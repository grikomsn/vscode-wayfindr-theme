# Generated brand assets

Generated on October 20, 2026 using the built-in image_gen tool. The live Wayfindr homepage supplied the gold/ink palette, directional arrow, rounded controls, dotted-map, and route references.

The user requested that the attempted Wayfindr mark be omitted. The selected icon is therefore a generic northeast arrow in a ring, and the selected cover has no logo. Discarded logo concepts are not included in the repository.

Final assets:

- `images/icon-direction.png` — square direction-arrow extension icon.
- `images/cover.png` — landscape README cover with a dotted map and route arcs.

The original `images/icon.svg` and `images/icon.png` are retained as legacy design sources. Theme builds never regenerate or overwrite the selected raster artwork.

## Final icon prompt

```text
Use case: logo-brand
Asset type: square VS Code color theme extension icon.
Primary request: A minimal direction-arrow icon for Wayfindr Theme. Do not depict or imitate the Wayfindr logo. The user explicitly wants the attempted W logo omitted.
Scene/backdrop: a completely flat muted golden yellow #EFBA5A square.
Subject: one bold deep-ink #101828 arrow pointing northeast, centered inside a thin circular deep-ink ring, with simple rounded line ends and plenty of space between the arrow and circle. Strong readable silhouette at 32 pixels. The arrow should be a conventional straight diagonal shaft ending in a clean right-angle arrowhead, without additional loops, letters or a W shape.
Composition/framing: a single small, balanced symbol centered with around 20 percent outer padding.
Style/medium: crisp flat graphic icon, restrained geometric design, no textures, no gradients, no 3D, no shadows.
Text: none.
Constraints: no W, no letterforms, no brand logo, no wordmark, no dots or extra marks, no trademark symbols, no watermark. Use only deep ink and gold.
```

## Cover creation prompt

The original cover was generated from the website screenshot and an initial icon concept. The emblem was subsequently removed with the correction below.

```text
Use case: ads-marketing
Asset type: wide GitHub repository and VS Code extension README cover, landscape approximately 2:1 aspect ratio, crisp professional graphic design.
Primary request: Create a cover for Wayfindr Theme, a collection of ten light and dark editor color themes.
Input images: Image 1 is the Wayfindr website style reference, particularly its warm gold field, rounded pill-shaped navigation, dotted world-map motif, and confident dark typography. Image 2 is the newly created extension icon; preserve that original connected W-route/upward-right-arrow symbol and sage waypoint dot as the cover's emblem. Both images are references for a new cover, not edit targets.
Composition/framing: An editorial, clean, spacious landscape banner. Large accurate title and smaller subtitle on the left, emblem and a subtle dotted global network/map with two or three sweeping route arcs on the right. Echo the rounded pill and route language from the website with generous margins. Include a small refined row of color swatches near the bottom to suggest the warm yellow, gray, ink, sage, plum and sky theme families.
Color palette: muted golden yellow #EFBA5A across the main background; deep ink #101828 typography and emblem; small accents sage #B1CEB3, sky #B8D8E4 and plum #A05F9A. Restrained neutral-gray panel or strip is acceptable to evoke the gray variants.
Text (verbatim): "Wayfindr Theme" as the only large title; "Ten palettes. One clear direction." as the subtitle; "For Visual Studio Code" as a small label. Render these words exactly, and no extra text.
Style/medium: polished modern brand graphic, crisp high-contrast typography, subtle halftone dots, flat and calm, no 3D, no photorealism, no complex dashboard mockups, no screenshots of invented code.
Constraints: Keep all text safely inside wide margins. Use the original icon from Image 2, not the official website wordmark. No official VS Code logo, no trademark symbols, no watermark, no other slogans.
```
