# Publishing

The release structure follows `inco-copilot-chat`, `openai-oauth-copilot-chat`, and `inception-copilot-chat`: npm with a committed lockfile, Changesets version pull requests, pinned Actions, a `VSCE_PAT` repository secret, and a GitHub release containing the Marketplace VSIX.

## Release flow

1. Add a note with `npm run changeset` for a user-visible change and merge it with the implementation.
2. The Release workflow opens or updates `chore: version extension`.
3. Review and merge that version pull request. CI must pass.
4. The workflow packages the versioned extension, publishes the exact VSIX using the secret, and creates the matching `vX.Y.Z` GitHub release.

The initial changeset prepares version 0.3.1. The setup push opens the version pull request; it does not publish while the changeset is pending. Changesets is used for versioning only; this extension is not published to npm.

## Marketplace credentials

Publisher: `grikomsn`. Extension: `wayfindr-theme`.

Store a dedicated Azure DevOps PAT in this repository's GitHub Actions secret named **VSCE_PAT**. Use only **Marketplace (Manage)** and select the narrowest organization scope accepted by Marketplace for the existing publisher. Verify with `vsce verify-pat grikomsn` before relying on it. Keep the value in protected process memory or the GitHub secret store, never in source, command arguments, logs, screenshots, or chat.

Existing PAT values cannot be displayed again from the settings list. Create a new dedicated token rather than regenerating a token used by another extension. Rotate this repository's secret before its expiration.

The Azure portal and current VS Code docs announce retirement of global PATs on December 1, 2026. This repository follows the requested sibling PAT setup; use an organization-scoped token if accepted. If global scope is required, plan migration to the documented Microsoft Entra or trusted-publishing flow before that date. [Publishing Extensions](https://code.visualstudio.com/api/working-with-extensions/publishing-extension.md), [Azure PAT management](https://learn.microsoft.com/en-us/azure/devops/organizations/accounts/use-personal-access-tokens-to-authenticate?view=azure-devops).

## Local packaging

```sh
npm ci
npm run check
npm run package
```

Packaging derives the filename from the manifest version, excludes development dependencies and Changesets files, and rewrites README asset links to the public GitHub repository. The generated icon and cover are committed artwork and are not regenerated by theme builds.

`npm run release` publishes the already-built package and requires `VSCE_PAT`. Use the automated version pull request for ordinary releases.
